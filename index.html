Ponte local do vsx

A ponte é o servidor Node do vsx. Ela executa o OpenCode e troca o código do GitHub por um token — o navegador não pode fazer essa troca sozinho, porque o GitHub não libera CORS.

  • No GitHub Pages a ponte precisa responder por fetch: exponha a porta (no Codespace, painel Ports → Visibility: Public) e informe o endereço público e a senha aqui.
  • Na mesma máquina, rode npm start e abra http://127.0.0.1:4173 — a ponte é a própria origem e nada mais é preciso.
  • O endereço de retorno da autorização é http://127.0.0.1:4173/oauth/callback (modo local) ou a própria URL da página do vsx (GitHub Pages) — cadastre exatamente ele no OAuth App.

Conectar workspace no Codespaces

Cada aluno roda a ponte do vsx dentro do próprio GitHub Codespace. Você pode criar seu Codespace a partir do template ou conectar por URL. Copie a URL pública da porta 4173 e a senha exibida no log do Codespace e informe-os aqui. O GitHub Pages passa a falar com esse workspace, com token obrigatório.

Abre a API do GitHub para listar, criar ou retomar seu Codespace (usa seu token conectado).

Usado ao criar um novo Codespace a partir do template.

  • Rode npm run start:codespace no seu Codespace ou use .devcontainer/.
  • Torne a porta 4173 pública nas Ports do Codespaces.
  • A URL tem o formato https://<nome>-4173.<domínio> e a senha aparece no log do workspace (ou em /tmp/vsx-codespace.log).
  • O workspace fica guardado neste navegador; use Desconectar para removê-lo.
